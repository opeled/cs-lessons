public static int What(Node<int> lst)
{
    if (lst.GetNext() == null)
        return 1;
    int len = What(lst.GetNext());
    if (lst.GetValue() < lst.GetNext().GetValue())
        return len + 1;
    return 1;
}

public static int Secret(Node<int> lst)
{
    if (lst == null)
        return 0;
    return Math.Max(What(lst), Secret(lst.GetNext()));
}

      (2) מה עושה Secret: הפעולה מחזירה את אורך הרצף העולה ממש הארוך ביותר בשרשרת.

      הסבר: Secret עוברת על כל חוליה, מחשבת בעזרת What את אורך הרצף העולה שמתחיל בה, ומחזירה את הגדול מבין כל הערכים האלה (עם 0 לשרשרת ריקה). בדוגמה: הרצפים שמתחילים בכל חוליה הם באורך 3, 2, 1, 4, 3, 2, 1, 1, והגדול ביותר הוא 4 (הרצף 2, 4, 6, 9).
    

    

      (3) סיבוכיות: O(n²).

      Secret מבצעת n קריאות (אחת לכל חוליה, ועוד אחת ל־null). בכל קריאה היא קוראת ל־What על שאר השרשרת, ו־What עצמה היא O(n): קריאה אחת לכל חוליה, עם מספר קבוע של פעולות בכל קריאה. מספר הכניסות ל־What הוא לכן:
      

      
⚠ שימו לב: What תמיד יורדת עד סוף השרשרת, גם כשהרצף נגמר מיד, כי הקריאה הרקורסיבית מתבצעת לפני ההשוואה. בשרשרת 9 → 1 → 2 → 3 התשובה היא 1, אבל עדיין מתבצעות 4 קריאות. לכן אי אפשר לטעון ש״בדרך כלל What קצרה״.

      
בכלליות n + (n−1) + … + 1 ≈ n²/2, ולכן O(n²). זהו הדפוס החוזר בבגרות: פעולה רקורסיבית ב־O(n) שנקראת מתוך פעולה רקורסיבית אחרת ב־O(n).

    בונוס
    
אפשר לעצור מוקדם?

    
תלמידה הציעה לשנות את What כך שתבדוק את ההשוואה לפני הקריאה הרקורסיבית, ותעצור כשהרצף נגמר:

    


public static int What2(Node<int> lst)
{
    if (lst.GetNext() == null)
        return 1;
    if (lst.GetValue() < lst.GetNext().GetValue())
        return 1 + What2(lst.GetNext());
    return 1;
}

      

        
    
          
  1. האם What2 מחזירה תמיד את אותו ערך כמו What?
    2. 
          
  2. מה הסיבוכיות של What2 בשרשרת 9 → 1 → 2 → 3? ובשרשרת 1 → 2 → 3 → 9?
    3. 
          
  3. אם Secret תשתמש ב־What2, האם הסיבוכיות שלה במקרה הגרוע תשתנה?
    4. 
        

      

    

    
(1) כן. שתיהן מחזירות את אורך הרצף העולה שמתחיל בחוליה הראשונה. ההבדל הוא רק בסדר: What2 מחליטה לפני שהיא קוראת, What קוראת ואז מחליטה.

    
(2) ב־9 → 1 → 2 → 3 What2 עוצרת אחרי קריאה אחת (9 אינו קטן מ־1). ב־1 → 2 → 3 → 9 היא עוברת את כל השרשרת. לכן במקרה הגרוע היא עדיין O(n), אבל במקרה הטוב היא O(1).

    
(3) לא. במקרה הגרוע (שרשרת עולה ממש) כל קריאה ל־What2 עוברת עד הסוף, ו־Secret נשארת O(n²). השיפור הוא רק במקרים ״נוחים״, וסיבוכיות נמדדת לפי המקרה הגרוע.
