public static int What(Node<int> lst)
{
    if (lst.GetNext() == null)
        return 1;
    int len = What(lst.GetNext());
    if (lst.GetValue() < lst.GetNext().GetValue())
        return len + 1;
    return 1;
}

ב. לפניכם הפעולה Secret:

public static int Secret(Node<int> lst)
{
    if (lst == null)
        return 0;
    return Math.Max(What(lst), Secret(lst.GetNext()));
}

סעיף א׳ (2)

  

    
מה עושה הפעולה What? הסבירו.

    

      What מחזירה את אורך הרצף העולה ממש שמתחיל בחוליה הראשונה של השרשרת.

      רצף שמתחיל בחוליה האחרונה הוא באורך 1. חוליה מצטרפת לרצף שמתחיל אחריה רק אם הערך שלה קטן ממש מהערך הבא (ואז len + 1). אם לא, הרצף שמתחיל בה הוא באורך 1, בלי קשר למה שקרה בהמשך.

      בדוגמה: 3 > 1, הרצף נשבר כבר בחוליה הראשונה. לכן What(lst) = 1.
    

    
⚠ טעות נפוצה: לכתוב ש־What ״מחזירה את אורך הרצף העולה הארוך ביותר בשרשרת״. לא נכון: What בודקת רק את הרצף שמתחיל בחוליה הראשונה. בדוגמה הרצף הארוך ביותר הוא 1, 2, 4 (באורך 3), אבל What מחזירה 1, כי הרצף שמתחיל ב־3 נשבר מיד. את הרצף הארוך ביותר מוצאת Secret, בסעיף ב׳.

סעיף ב׳ (2)

  

    
מה עושה הפעולה Secret? הסבירו.

    

      Secret מחזירה את אורך הרצף העולה ממש הארוך ביותר בשרשרת.

      Secret עוברת על כל חוליה, מחשבת בעזרת What את אורך הרצף העולה שמתחיל בה, ומחזירה את הגדול מבין כל הערכים האלה (עם 0 לשרשרת ריקה).
    

    
בדוגמה: הרצפים שמתחילים בכל חוליה הם באורך 1, 3, 2, 1, והגדול ביותר הוא 3 (הרצף 1, 2, 4).

  







  
סעיף ב׳ (3)

  

    
מהי סיבוכיות זמן הריצה של Secret? נמקו.

    

      O(n²).

      Secret מבצעת n קריאות (אחת לכל חוליה, ועוד אחת ל־null). בכל קריאה היא קוראת ל־What על שאר השרשרת, ו־What עצמה היא O(n): קריאה אחת לכל חוליה.
    

    
⚠ What תמיד יורדת עד סוף השרשרת, גם כשהרצף נגמר מיד, כי הקריאה הרקורסיבית מתבצעת לפני ההשוואה. בשרשרת 9 → 1 → 2 → 3 התשובה היא 1, אבל עדיין 4 קריאות.

    

      מספר הכניסות ל־What הוא לכן:
      

      
בכלליות n + (n−1) + … + 1 ≈ n²/2, ולכן O(n²). זהו הדפוס החוזר בבגרות: פעולה רקורסיבית ב־O(n) שנקראת מתוך פעולה רקורסיבית אחרת ב־O(n).

    

  







  
סעיף ב׳ (4) חשיבה הפוכה: לבנות קלט לתשובה נתונה

  
כתבו שרשרת בת 5 חוליות שעבורה Secret תחזיר 1, ושרשרת בת 5 חוליות שעבורה היא תחזיר 5.

  

    

      Secret = 1
      
רמז: שרשרת שאין בה אף זוג סמוך עולה ממש.

      

      
Secret = 1 · שימו לב ש־4, 4 אינו ״עולה ממש״, ולכן גם חזרות מותרות.

    

    

      Secret = 5
      
רמז: כל השרשרת היא רצף עולה ממש אחד.

      

      
Secret = 5 · ואם החוליה האחרונה הייתה 4? אז 4, 4 שובר את הרצף: Secret = 4.

    

  







  
בונוס אפשר לעצור מוקדם?

  

    

      
תלמידה הציעה לשנות את What כך שתבדוק את ההשוואה לפני הקריאה הרקורסיבית, ותעצור כשהרצף נגמר:


public static int What2(Node<int> lst)
{
    if (lst.GetNext() == null)
        return 1;
    if (lst.GetValue() < lst.GetNext().GetValue())
        return 1 + What2(lst.GetNext());
    return 1;
}

    

    

      
(1) האם What2 מחזירה תמיד את אותו ערך כמו What?
כן. שתיהן מחזירות את אורך הרצף העולה שמתחיל בחוליה הראשונה. ההבדל הוא רק בסדר: What2 מחליטה לפני שהיא קוראת, What קוראת ואז מחליטה.

      
(2) מה הסיבוכיות של What2 בשרשרת 9 → 1 → 2 → 3? ובשרשרת 1 → 2 → 3 → 9?
בראשונה What2 עוצרת אחרי קריאה אחת (9 אינו קטן מ־1). בשנייה היא עוברת את כל השרשרת. במקרה הגרוע היא עדיין O(n), אבל במקרה הטוב O(1).

      
(3) אם Secret תשתמש ב־What2, האם הסיבוכיות שלה במקרה הגרוע תשתנה?
לא. במקרה הגרוע (שרשרת עולה ממש) כל קריאה ל־What2 עוברת עד הסוף, ו־Secret נשארת O(n²). סיבוכיות נמדדת לפי המקרה הגרוע.
