איך ניגשים לשאלת כתיבה על מערכים, מחרוזות ומספרים

  1. קוראים את כותרת הפעולה. מה הפעולה מקבלת? האם היא מחזירה ערך, מדפיסה או משנה את המערך שקיבלה? כותרת שניתנה בשאלה מעתיקים כמו שהיא. פעולה חיצונית נכתבת עם public static ופעולה פנימית בלי static.
  2. מסמנים כל משפט שמתחיל ב"הניחו" וכל הערה. לדוגמה: "הניחו שבמערך יש לפחות מספר אי־זוגי אחד" אומר שאין צורך לטפל במערך שאין בו מספר כזה. "אין לשנות את המערך" אומר שאת התוצאה בונים במערך חדש.
  3. מזהים את התבנית. כמעט כל שאלה נפתרת באחת משמונה התבניות שבהמשך או בשילוב של שתיים מהן. הטבלה שלמטה עוזרת לזהות את התבנית לפי הניסוח.
  4. עוקבים אחרי הקוד שכתבתם עם הדוגמה שבשאלה. בודקים במיוחד את הסיבוב הראשון ואת הסיבוב האחרון של הלולאה, כי שם נמצאות רוב הטעויות באינדקסים.

מערך חד־ממדי: שמונה תבניות

1. מונה, צובר וממוצע

int count = 0, sum = 0;
for (int i = 0; i < a.Length; i++)
    if (a[i] > 0)
    {
        count++;
        sum += a[i];
    }
double avg = (double)sum / count;

התוצאה של חילוק שני שלמים היא מספר שלם (7 / 2 הוא 3) ולכן ממירים ל־double לפני החילוק. כשייתכן ש־count הוא 0, בודקים זאת לפני שמחלקים.

2. הערך הגדול ביותר והאינדקס שלו

public static int MaxIndex(int[] a)
{
    int best = 0;
    for (int i = 1; i < a.Length; i++)
        if (a[i] > a[best])
            best = i;
    return best;
}

best הוא אינדקס ולא ערך. הוא מתחיל ב־0, האינדקס של התא הראשון. כששומרים את הערך הגדול ביותר במקום את האינדקס שלו, מתחילים מ־a[0] ולא מהמספר 0, כי ייתכן שכל הערכים שליליים. כשכותבים > נשמר המופע הראשון של הערך הגדול ביותר וכשכותבים >= נשמר המופע האחרון. הערך עצמו הוא a[best].

3. האם קיים, האם כולם

public static bool Exists(int[] a, int x)
{
    for (int i = 0; i < a.Length; i++)
        if (a[i] == x)
            return true;
    return false;
}

זהו חיפוש סדרתי. מחזירים false רק אחרי הלולאה. מי שכותב else return false בתוך הלולאה בודק רק את התא הראשון. ב"האם כולם" הסדר הפוך: בתוך הלולאה מחזירים false כשתא אינו מקיים את התנאי ואחריה מחזירים true.

4. שכנים ורצפים (הרצף העולה הארוך ביותר)

int cur = 1, best = 1;
for (int i = 1; i < a.Length; i++)
{
    if (a[i] > a[i - 1]) cur++;
    else cur = 1;
    if (cur > best) best = cur;
}

כשניגשים ל־a[i - 1] הלולאה מתחילה ב־1. כשניגשים ל־a[i + 1] תנאי הלולאה הוא i < a.Length - 1. רצף חדש מתחיל באורך 1 ולא באורך 0, כי התא הנוכחי כבר שייך אליו. את best מעדכנים בכל סיבוב, אחרת רצף שמגיע עד סוף המערך לא נבדק.

5. מערך מונים

כשהערכים הם מספרים קטנים (ספרות, מספרי מוצר, מספרי קומה), הערך עצמו משמש אינדקס במערך של מונים.

// כל הערכים במערך הם בין 0 ל־9
int[] cnt = new int[10];
for (int i = 0; i < a.Length; i++)
    cnt[a[i]]++;

במערך חדש של מספרים שלמים יש 0 בכל התאים. בסוף הלולאה cnt[d] הוא מספר המופעים של הערך d. לערכים מ־0 עד k דרוש מערך בגודל k + 1. כשהערכים מתחילים ב־1 (לדוגמה: שירים שמספרם 1 עד 40) יוצרים מערך בגודל 41 ולא משתמשים בתא 0. דרך אחרת היא מערך בגודל 40, שבו המונה של הערך x נמצא בתא cnt[x - 1]. באותה צורה צוברים סכום לכל ערך בהוראה sum[key] += value (לדוגמה: סכום המכירות של כל מוצר).

6. סינון למערך חדש בגודל מדויק

public static int[] Positives(int[] a)
{
    int count = 0;
    for (int i = 0; i < a.Length; i++)
        if (a[i] > 0) count++;
    int[] res = new int[count];
    int k = 0;
    for (int i = 0; i < a.Length; i++)
        if (a[i] > 0)
        {
            res[k] = a[i];
            k++;
        }
    return res;
}

גודל של מערך נקבע כשיוצרים אותו. לכן סופרים קודם ורק אחר כך יוצרים וממלאים. למערך החדש יש אינדקס משלו (k). התנאי בשתי הלולאות חייב להיות זהה.

7. הזזה, הכנסה ומחיקה

במערך שמלא רק בחלקו, count הוא מספר התאים המלאים והם נמצאים באינדקסים 0 עד count - 1.

// מכניסים ערך חדש לאינדקס pos
for (int i = count; i > pos; i--)
    a[i] = a[i - 1];
a[pos] = x;
count++;

// מוחקים את התא שבאינדקס pos
for (int i = pos; i < count - 1; i++)
    a[i] = a[i + 1];
count--;

לפני הכנסה בודקים שיש מקום: count < a.Length. כשמזיזים ימינה הלולאה עוברת מהסוף להתחלה וכשמזיזים שמאלה היא עוברת מההתחלה לסוף. אחרת ערך של תא נדרס לפני שהועתק. כשהמערך מלא והשאלה קובעת שהערך האחרון יוצא ממנו, לולאת ההכנסה מתחילה ב־i = a.Length - 1 ולא מגדילים את count.

8. כל הזוגות

// האם יש שני תאים שסכומם k
for (int i = 0; i < a.Length - 1; i++)
    for (int j = i + 1; j < a.Length; j++)
        if (a[i] + a[j] == k)
            return true;
return false;

j מתחיל ב־i + 1 ולכן תא אינו נבדק מול עצמו וכל זוג נבדק פעם אחת. כשמחפשים לכל תא "תא אחר" שמקיים את התנאי שבשאלה, j עובר על כל המערך ומדלגים על המקרה j == i. סיבוכיות זמן הריצה היא O(n²).

באותה צורה בודקים אם כל הערכים של מערך אחד מופיעים במערך אחר: לכל תא במערך הראשון מחפשים את הערך שלו במערך השני (תבנית 3).

מערך חדש או שינוי של המערך שהתקבל

פעולה שמקבלת מערך מקבלת הפניה אליו. השמה לתא (arr[i] = 5) משנה את המערך של מי שזימן את הפעולה. לעומת זאת ההשמה arr = temp בתוך הפעולה משנה רק את ההפניה המקומית והמערך המקורי נשאר כמו שהיה. כשבונים את התוצאה במערך עזר ונדרש לשנות את המערך שהתקבל, מעתיקים בסוף תא אחרי תא: arr[i] = temp[i].

מערך דו־ממדי

מערך של 3 שורות ו־4 עמודות: int[,] m = new int[3, 4]. התא שבשורה r ובעמודה c הוא m[r, c]. מספר השורות הוא m.GetLength(0) ומספר העמודות הוא m.GetLength(1).

int rows = m.GetLength(0);
int cols = m.GetLength(1);
for (int r = 0; r < rows; r++)
{
    int sum = 0;        // סכום השורה r
    for (int c = 0; c < cols; c++)
        sum += m[r, c];
    Console.WriteLine(sum);
}

לסכום של כל עמודה הלולאה החיצונית עוברת על העמודות והפנימית על השורות. את המשתנה sum מאפסים בתוך הלולאה החיצונית, אחרת הסכומים מצטברים משורה לשורה.

מה רוצים לעשותאיך כותבים
המערך ריבועיrows == cols
האלכסון הראשיm[i, i]
האלכסון המשניm[i, cols - 1 - i]
// סכום ארבעת השכנים של תא אחד
int s = 0;
if (r > 0)        s += m[r - 1, c];
if (r < rows - 1) s += m[r + 1, c];
if (c > 0)        s += m[r, c - 1];
if (c < cols - 1) s += m[r, c + 1];

לתא שבקצה המערך חסר שכן באחד הכיוונים לפחות. לפני כל גישה לשכן בודקים שהאינדקס שלו בתוך המערך.

ספירת אותיות במערך של 26 מונים

int[] cnt = new int[26];
for (int i = 0; i < s.Length; i++)
    if (s[i] >= 'a' && s[i] <= 'z')
        cnt[s[i] - 'a']++;

זו תבנית 5 של המערכים. בסוף cnt[0] הוא מספר המופעים של האות a ו־cnt[25] של האות z. לאותיות גדולות מחסירים 'A'.

בניית מחרוזת חדשה

string res = "";
for (int i = s.Length - 1; i >= 0; i--)
    res += s[i];       // המחרוזת בסדר הפוך

אי אפשר לשנות תו בתוך מחרוזת קיימת: ההשמה s[i] = 'x' היא שגיאה. במקום זה בונים מחרוזת חדשה תו אחרי תו. כשהתווים אינם נקבעים לפי הסדר מההתחלה לסוף, ממלאים מערך char[] arr ובסוף יוצרים ממנו מחרוזת: new string(arr).

כש־p הוא 10 בחזקת k, n % p הוא k הספרות הימניות ו־n / p הוא המספר בלי k הספרות הימניות. את p מחשבים בלולאה: מתחילים מ־1 ומכפילים ב־10 בכל סיבוב, k פעמים.

Math.Pow ו־Math.Sqrt מחזירות double. המרה ל־int מוחקת את החלק שאחרי הנקודה ואינה מעגלת: (int)Math.Sqrt(23) הוא 4.

את סכום המחלקים של n בלי n עצמו מחשבים כך: d עובר מ־1 עד n - 1 ומוסיפים את d לסכום כשמתקיים n % d == 0.

// עוברים על הספרות מימין לשמאל
int sum = 0, digits = 0, rev = 0;
while (n > 0)
{
    int d = n % 10;
    sum += d;             // סכום הספרות
    digits++;             // מספר הספרות
    rev = rev * 10 + d;   // המספר בסדר הפוך
    n /= 10;
}

בסוף הלולאה n הוא 0. כשצריך את המספר המקורי אחרי הלולאה (לדוגמה: כשמשווים אליו את התוצאה), מעתיקים אותו קודם למשתנה אחר ומפרקים את ההעתק.

public static bool IsPrime(int n)
{
    if (n < 2) return false;
    for (int d = 2; d * d <= n; d++)
        if (n % d == 0)
            return false;
    return true;
}

מספיק לבדוק מחלקים עד השורש של n ולכן התנאי הוא d * d <= n.

טבלת מעקב ללולאה

  1. פותחים עמודה לכל משתנה שהשאלה מבקשת. כשיש if בתוך הלולאה מוסיפים עמודה לתנאי.
  2. השורה הראשונה מציגה את הערכים לפני הלולאה. אחריה באה שורה אחת לכל סיבוב.
  3. ממלאים כל שורה לפי סדר ההוראות בגוף הלולאה. כשהוראה משתמשת במשתנה, לוקחים את הערך שיש בו באותו רגע.
  4. בשורה האחרונה רושמים את הבדיקה שבה תנאי הלולאה אינו מתקיים.
  5. אחרי הטבלה כותבים במפורש את מה שנשאל: הפלט, הערך המוחזר או תוכן המערך בסוף.
int[] a = { 2, 5, 4, 8 };
int s = 0;
for (int i = 1; i < a.Length; i++)
{
    a[i] = a[i] - a[i - 1];
    s += a[i];
}

בסוף הריצה המערך הוא 2, 3, 1, 7 וערכו של s הוא 11.

בסיבוב השני a[1] כבר שווה 3 ולא 5, כי הסיבוב הראשון שינה אותו. מי שמחשב לפי המערך המקורי מקבל 4 - 5 וטועה מכאן והלאה. כשהקוד משנה את המערך, רושמים את המערך בצד הטבלה ומעדכנים אותו אחרי כל סיבוב.

סיבוכיות זמן הריצה של קוד עם לולאות

כששואלים על סיבוכיות זמן הריצה, בודקים כמה פעמים מתבצע גוף הלולאה הפנימית ביותר. לדוגמה: שלוש לולאות מקוננות שעוברות על כל השלשות במערך רצות בזמן O(n³). לולאה על מערך בגודל n ואחריה לולאה על מערך מונים בגודל k רצות יחד בזמן O(n + k). לולאה שעוברת על מספר קבוע של תאים (10 ספרות, 26 אותיות) רצה בזמן O(1).

מה חוזר בבגרות בשאלות על מערכים, מחרוזות ומספרים

הנושאים האלה מופיעים בבגרות גם בתוך שאלות על מחלקות ועל מבני נתונים. אלה הדברים שחוזרים:

  • שאלת מעקב. נתון קטע קוד קצר עם לולאה אחת והשאלה מבקשת: "עקבו בעזרת טבלת מעקב... בטבלת המעקב יש לכלול עמודה בעבור כל אחד מן המשתנים האלה". הטבלה חייבת לכלול את העמודות שנדרשו.
  • הגדרה חדשה עם שם במירכאות. השאלה מגדירה מושג שלא למדתם ומבקשת לבדוק אם מספר, מערך או מחרוזת מתאימים להגדרה: "מספר נרקיסיסטי", "מספר מושלם", "קפרקר מאוזן", "מערך ממוין בחיוביים", "מערך הפרשים", "מערך מושלם", "מערך פינה", "איבר שוויון", "מחרוזת כפולה". עובדים רק לפי ההגדרה ולפי הדוגמאות שבשאלה.
  • סעיף ב משתמש בפעולה מסעיף א. בסעיף א כותבים פעולה שבודקת מספר אחד או תא אחד. בסעיף ב עוברים על טווח או על מערך ומזמנים אותה. בשאלה כתוב "יש להשתמש בפעולה שכתבתם בסעיף א" או "חובה להיעזר".
  • מערך שמלא רק בחלקו. למחלקה יש מערך ותכונה נוספת שסופרת כמה תאים מלאים (count, amount, current). סורקים עד המונה ולא עד Length.

אחרי המעקב: "כתבו דוגמה ל... שבעבורו..."

יש שאלות שבהן בא אחרי המעקב סעיף שמבקש קלט שנותן תוצאה מסוימת. לדוגמה: מערך בגודל 4 של מספרים גדולים מ־0 שעבורו המונה שבקוד יישאר 0. דוגמה אחרת: מספר גדול מ־1 שעבורו יודפס 1.

אחרי המעקב כותבים בצד משפט אחד שמתאר מה הלולאה עושה בכל סיבוב: מה היא בודקת ומה היא מוסיפה. לפי המשפט הזה בונים קלט קטן. בודקים שהקלט עומד בכל ההגבלות שבסעיף (הגודל, "גדולים מ־0") ועוקבים בקצרה אחרי הקוד עם הקלט הזה.

סעיף ב: עוברים על טווח ומזמנים את הפעולה מסעיף א

// מדפיסה כל מספר בטווח שעובר את הבדיקה
public static void PrintAll(int n)
{
    for (int x = 1; x <= n; x++)
        if (IsSpecial(x))
            Console.WriteLine(x);
}

PrintAll מדפיסה כל מספר מ־1 עד n (כולל) ש־IsSpecial, הפעולה מסעיף א, מחזירה עבורו true. המילה "כולל" מחייבת <=. אין לכתוב שוב את הבדיקה של סעיף א בתוך הלולאה.

כשמבקשים לבדוק טענה על טווח גדול (לדוגמה: שאין עד 999,999 מספר אי־זוגי ששווה לסכום המחלקים שלו שקטנים ממנו), מחזירים false ברגע שנמצא מספר שסותר את הטענה ומחזירים true רק אחרי הלולאה.

המילים שקובעות את סימן ההשוואה

ב"רוב" וב"חצי" מכפילים את המונה ב־2 במקום לחלק את גודל המערך ב־2, כי 7 / 2 הוא 3 ואז 3 מתוך 7 נחשבים בטעות לחצי.

מה הפעולה עושה עם המערך

  • "מחזירה מערך חדש בגודל זהה" ו"אין לשנות את המערך": יוצרים new int[arr.Length] וממלאים אותו.
  • "גודל המערך המוחזר הוא כמספר האיברים ש...": זו תבנית 6, שבה סופרים לפני שיוצרים את המערך.
  • הפעולה היא void ומסדרת את המערך עצמו: בונים את התוצאה במערך עזר ומעתיקים בחזרה תא אחרי תא.
  • "אם הערך כבר מופיע, המערך יישאר ללא שינוי": קודם מחפשים את הערך בכל המערך ורק אחרי שהחיפוש הסתיים מתחילים להזיז.
  • הכנסה למערך שמלא רק בחלקו: בודקים קודם שיש מקום ומחזירים false כשאין. אחרי ההכנסה מגדילים את המונה.

מחרוזות: מה נדרש בפועל

  • בדרך כלל מספיקים Length, גישה לתו ב־s[i] והשוואת תווים ב־==.
  • כשמשווים שתי מחרוזות תו מול תו, בודקים קודם שהאורכים שווים. רק אז ניגשים לאותו אינדקס בשתיהן.
  • כשבודקים אם שני החצאים של מחרוזת זהים, מחזירים false מיד כשהאורך אי־זוגי. אחרת משווים את s[i] ל־s[i + s.Length / 2].
  • יש שאלות שבהן מערך של אינדקסים p קובע את הסדר החדש של תווי המחרוזת s ואת התוצאה בונים במערך תווים res. בודקים על הדוגמה שבשאלה איזו השמה נכונה: res[p[i]] = s[i] או res[i] = s[p[i]].

משתנה שמתאפס באמצע הסריקה

יש שאלות שבהן המערך מתחלק לקטעים. הצובר מתאפס בסוף כל קטע והתשובה היא התוצאה הגדולה ביותר שהתקבלה בקטע אחד.

  • הסכום הגדול ביותר של תאים שבין שני אפסים: כשמגיעים לתא שערכו 0 משווים את הסכום שנצבר לסכום הגדול ביותר שנמצא ומאפסים את הצובר. התאים שלפני ה־0 הראשון ואחרי ה־0 האחרון אינם נכללים בחישוב.
  • הרצף העולה הארוך ביותר: כאן המונה חוזר ל־1 בסוף כל רצף (תבנית 4).
  • בשאלות מעקב מופיע גם צובר שמאפסים אותו בכל פעם שערכו נעשה שלילי.

טעויות נפוצות

כל שורה כאן מתארת טעות שתלמידים עושים ולא הנחיה.

אינדקסים וגבולות

  • כותבים i <= a.Length וחורגים מהמערך. התא האחרון הוא a[a.Length - 1].
  • ניגשים ל־a[i + 1] או ל־a[i - 1] בלי לשנות את גבולות הלולאה.
  • בזוג הסימטרי כותבים a[a.Length - i] במקום a[a.Length - 1 - i].
  • סורקים מערך שמלא רק בחלקו עד Length.
  • משתמשים באינדקס של המערך המקורי גם במערך התוצאה (תבנית 6).
  • במעקב: מחשבים לפי המערך המקורי אחרי שהקוד כבר שינה אותו.

תנאים, חישוב וקריאת השאלה

  • ב"האם קיים" מחזירים false בתוך הלולאה כבר כשהתא הראשון אינו מתאים (תבנית 3).
  • מאתחלים את הערך הגדול ביותר במספר 0 במקום ב־a[0] כשייתכנו ערכים שליליים.
  • מתבלבלים בין > ל־>= או בין && ל־||.
  • כותבים שרשרת של else if כשכל תנאי צריך להיבדק בנפרד וכמה מהם יכולים להתקיים יחד.
  • מפרקים את המספר לספרות ואחר כך משתמשים בו כאילו לא השתנה.
  • מדפיסים את התוצאה כשהשאלה דורשת להחזיר אותה או להפך.
