שרשרת חוליות

דף עזר לבגרות במדעי המחשב, שאלון 899271
הקוד בשפת C#

איך חושבים על שרשרת חוליות

משתנה מטיפוס Node<int> אינו מכיל חוליה. הוא מכיל הפניה לחוליה. בסרטוט הוא מופיע כחץ שמפנה אל החוליה. אל השרשרת כולה מגיעים רק דרך ההפניה לחוליה הראשונה שלה. החוליה הראשונה נקראת ראש השרשרת. לפני שכותבים קוד מסרטטים שרשרת קטנה עם ההפניות ועונים על שלוש שאלות:

  1. האם ההוראה משנה את השרשרת? ההוראה p = p.GetNext() מזיזה רק את ההפניה p והשרשרת נשארת כפי שהייתה. רק SetNext ו־SetValue משנות את השרשרת עצמה.
  2. האם ההפניה יכולה להיות null? לפני כל p.GetValue() ולפני כל p.GetNext() מוודאים ש־p אינה null. בודקים את הקוד על שרשרת ריקה, על שרשרת בת חוליה אחת ועל המצב שבו ההפניה מגיעה לחוליה האחרונה.
  3. האם החוליה הראשונה יכולה להתחלף? אם כן, הפעולה חייבת להחזיר את ההפניה לחוליה הראשונה החדשה.

בסרטוט p מפנה לחוליה השנייה. p.GetValue() הוא 7 ו־p.GetNext() היא החוליה שערכה 6. כשהשרשרת ריקה, ההפניה אליה היא null.

כל חוליה היא גם ראש של השרשרת שמתחילה בה. לכן אפשר להעביר את p או את p.GetNext() לפעולה שמקבלת שרשרת והפעולה תטפל רק בחוליה שקיבלה ובחוליות שאחריה.

הפעולהמה מתקבל
new Node<int>(x)חוליה חדשה שערכה x
new Node<int>(x, q)חוליה חדשה שערכה x ואחריה q
p.GetValue()הערך שבחוליה
p.GetNext()החוליה הבאה או null
p.SetValue(x)הערך שבחוליה משתנה ל־x
p.SetNext(q)החוליה שאחרי p היא מעכשיו q
p.HasNext()true אם יש חוליה אחרי p

סריקה של שרשרת

מעבר על כל החוליות

public static int Sum(Node<int> lst)
{
    int sum = 0;
    Node<int> p = lst;
    while (p != null)
    {
        sum += p.GetValue();
        p = p.GetNext();
    }
    return sum;
}

באותו מבנה של לולאה סופרים חוליות ומחפשים מקסימום. את המקסימום מאתחלים בערך של החוליה הראשונה ולא ב־0, כי ייתכנו ערכים שליליים.

חיפוש שמחזיר הפניה לחוליה

public static Node<int> Find(Node<int> lst,
                             int x)
{
    Node<int> p = lst;
    while (p != null && p.GetValue() != x)
        p = p.GetNext();
    return p;
}

בתנאי הלולאה בודקים קודם p != null ורק אחר כך פונים ל־p.GetValue(). כאשר x אינו בשרשרת, הפעולה מחזירה null. אם הפעולה צריכה להחזיר bool, כותבים בסופה return p != null;

מה רוצים לעשותתנאי הלולאההערה
לעבור על כל החוליותp != nullאחרי הלולאה p היא null
לעצור על החוליה האחרונהp.GetNext() != nullכך מגיעים לחוליה האחרונה כשרוצים לחבר אחריה חוליה. בשרשרת ריקה התנאי הזה גורם לשגיאה, כי p היא null
לבדוק את החוליה שאחרי pp != null && p.GetNext() != nullהתנאי מתאים כשמשווים חוליה לחוליה הבאה או מוחקים את החוליה הבאה

כשצריך להגיע לחלק מסוים של השרשרת (לחצי השני או לשלוש החוליות האחרונות), סופרים קודם את החוליות בסריקה אחת. אחר כך מחשבים מהספירה כמה חוליות יש לפני החלק הזה, מסמנים את המספר ב־k ומתקדמים מראש השרשרת k חוליות: for (int i = 0; i < k; i++) p = p.GetNext();

הכנסה ומחיקה של חוליות

הכנסת חוליה אחרי החוליה p

Node<int> q = new Node<int>(x);
q.SetNext(p.GetNext());   // 1
p.SetNext(q);             // 2

סדר השורות חשוב. אם מבצעים קודם את שורה 2, ההפניה להמשך השרשרת אובדת. אפשר לכתוב גם בשורה אחת: p.SetNext(new Node<int>(x, p.GetNext()));

מחיקת החוליה שאחרי p

p.SetNext(p.GetNext().GetNext());

כדי למחוק חוליה צריך הפניה לחוליה שלפניה. לכן עוצרים חוליה אחת לפני החוליה שרוצים למחוק ובודקים את p.GetNext().GetValue(). את הוראת המחיקה מותר לבצע רק כאשר p.GetNext() אינה null. לחוליה הראשונה אין חוליה קודמת ולכן מוחקים אותה כך: lst = lst.GetNext();

מתי החוליה הראשונה מתחלפת ומה עושים אז

פעולה שמקבלת את lst מקבלת עותק של ההפניה. השמה ל־lst בתוך הפעולה אינה משנה את המשתנה של מי שזימן אותה. החוליה הראשונה יכולה להתחלף בהכנסה בתחילת השרשרת, במחיקת החוליה הראשונה, בהכנסה לשרשרת ממוינת ובהעברת חוליות מסוף השרשרת לתחילתה. פעולה שעלולה להחליף את החוליה הראשונה מחזירה Node<int> והזימון שלה נכתב כך: lst = RemoveAll(lst, x);

כאשר השרשרת היא תכונה של מחלקה והפעולה היא פעולה פנימית של המחלקה, מעדכנים את התכונה עצמה: this.lst = this.lst.GetNext();

כשמפצלים שרשרת לשתיים אחרי החוליה cut, שומרים קודם את ההפניה לחוליות שאחריה ורק אחר כך מנתקים: Node<int> rest = cut.GetNext(); cut.SetNext(null);

מחיקת כל החוליות שערכן x

public static Node<int> RemoveAll(
                    Node<int> lst, int x)
{
    while (lst != null && lst.GetValue() == x)
        lst = lst.GetNext();
    Node<int> p = lst;
    while (p != null && p.GetNext() != null)
    {
        if (p.GetNext().GetValue() == x)
            p.SetNext(p.GetNext().GetNext());
        else
            p = p.GetNext();
    }
    return lst;
}

הלולאה הראשונה מוחקת את החוליות שערכן x בתחילת השרשרת. בלולאה השנייה לא מתקדמים אחרי מחיקה, כי גם החוליה הבאה עלולה להכיל את x.

הכנסה לשרשרת ממוינת בסדר עולה

public static Node<int> InsertSorted(
                    Node<int> lst, int x)
{
    if (lst == null || x <= lst.GetValue())
        return new Node<int>(x, lst);
    Node<int> p = lst;
    while (p.GetNext() != null
           && p.GetNext().GetValue() < x)
        p = p.GetNext();
    p.SetNext(new Node<int>(x, p.GetNext()));
    return lst;
}

בודקים את הקוד על ארבעה מקרים: שרשרת ריקה, הכנסה לפני החוליה הראשונה, הכנסה באמצע והכנסה אחרי החוליה האחרונה. הלולאה עוצרת על החוליה האחרונה שערכה קטן מ־x.

בניית שרשרת חדשה

כשהסדר אינו חשוב: הכנסה בתחילת השרשרת

Node<int> result = null;
Node<int> p = lst;
while (p != null)
{
    if (p.GetValue() % 2 == 0)
        result = new Node<int>(p.GetValue(),
                               result);
    p = p.GetNext();
}
return result;

הקוד בונה שרשרת חדשה מהערכים הזוגיים של lst. הערכים מתקבלים בסדר הפוך לסדר שבו נסרקו. כאשר כל ערך צריך להופיע פעם אחת, בודקים לפני ההכנסה בעזרת פעולת חיפוש שהערך עדיין לא נמצא ב־result.

כשצריך לשמור על הסדר: הפניה לחוליה האחרונה

Node<int> first = null, last = null;
Node<int> p = lst;
while (p != null)
{
    if (p.GetValue() % 2 == 0)
    {
        Node<int> q = new Node<int>(p.GetValue());
        if (first == null)
            first = q;
        else
            last.SetNext(q);
        last = q;
    }
    p = p.GetNext();
}
return first;

גם כאן נבנית שרשרת של הערכים הזוגיים, הפעם בסדר המקורי. last מפנה תמיד לחוליה האחרונה שהוכנסה ולכן כל הכנסה מתבצעת בזמן O(1).

חוליית דמה. יש שאלות שבהן הקוד יוצר בהתחלה חוליה שהערך שלה אינו חשוב (זו חוליית הדמה), מחבר אחריה את החוליות ומחזיר בסוף את החוליה שאחרי חוליית הדמה.

שתי שרשראות ושרשרת של עצמים

בדיקה שחוזרים עליה מכל חוליה

Node<int> start = lst2;
while (start != null)
{
    if (Check(lst1, start))
        return true;
    start = start.GetNext();
}
return false;

לדוגמה: Check בודקת אם השרשרת lst1 מופיעה ב־lst2 החל מהחוליה start. מזמנים אותה שוב ושוב ובכל פעם מעבירים לה חוליה אחרת בתור ראש השרשרת. אחרי בדיקה שנכשלה מתקדמים חוליה אחת בלבד.

שרשרת שהערכים שלה הם עצמים

Node<Game> p = lst;
while (p != null)
{
    Game g = p.GetValue();
    if (g.GetPrice() < 50)
        g.SetPrice(g.GetPrice() + 5);
    p = p.GetNext();
}

Game הוא משחק שיש לו שם ומחיר. GetValue מחזירה הפניה לעצם שבחוליה ולכן g.SetPrice משנה את העצם שבשרשרת. חוליה חדשה נוצרת כך: new Node<Game>(new Game("a", 30)).

כשהערך הוא תור (Node<Queue<int>>), פעולה שמוציאה איברים מהתור p.GetValue() מרוקנת את התור שבשרשרת עצמה.

התקדמות בשתי שרשראות ממוינות בסדר עולה

// כמה ערכים מופיעים בשתי השרשראות
int count = 0;
while (a != null && b != null)
{
    if (a.GetValue() < b.GetValue())
        a = a.GetNext();
    else if (a.GetValue() > b.GetValue())
        b = b.GetNext();
    else
    {
        count++;
        a = a.GetNext();
        b = b.GetNext();
    }
}

a ו־b מפנות לראשי שתי השרשראות. בכל סיבוב מקדמים את ההפניה לחוליה שערכה קטן יותר. אף הפניה אינה חוזרת אחורה ולכן זמן הריצה הוא O(n + m), כאשר n ו־m הם מספר החוליות בכל אחת מהשרשראות. הקוד נכון רק כאשר בכל שרשרת הערכים שונים זה מזה.

כשמשווים חוליה מול חוליה (האם שתי שרשראות זהות, האם אחת היא התחלה של השנייה), מקדמים את שתי ההפניות בכל סיבוב. כשמוצאים שני ערכים שונים מחזירים false. הלולאה נעצרת כשאחת השרשראות נגמרת ואחריה בודקים איזו מהן נגמרה. לדוגמה: השרשראות זהות רק אם שתיהן נגמרו יחד, כלומר a == null && b == null.

מעקב אחרי פעולה על שרשרת

  1. מסרטטים את השרשרת: מלבן לכל חוליה, חץ לחוליה הבאה ו־null בסוף.
  2. מסמנים כל משתנה מטיפוס חוליה (lst, p, temp) בתווית עם חץ אל החוליה שהוא מפנה אליה.
  3. בהוראה p = p.GetNext() מעבירים את התווית p לחוליה הבאה. החיצים שבין החוליות אינם משתנים.
  4. בהוראה p.SetNext(q) מוחקים את החץ שיוצא מהחוליה של p ומסרטטים חץ חדש אל החוליה של q.
  5. בסוף קוראים את השרשרת מההפניה שהפעולה מחזירה, לאורך החיצים, עד null.

בדוגמה שמשמאל הפעולה מחזירה הפניה לחוליה שערכה 3. אם לא שומרים את הערך המוחזר, המשתנה של מי שזימן את הפעולה עדיין מפנה לחוליה הראשונה המקורית והשרשרת שלו מתחילה ב־1.

מה חוזר בשאלות השרשרת בבגרות

  • ברוב השאלות נדרשים לכתוב פעולה. שאלת מעקב על שרשרת נדירה יותר והפעולה שמופיעה בה היא בדרך כלל רקורסיבית.
  • סעיף ב׳ נשען על סעיף א׳. בסעיף א׳ כותבים פעולה שמטפלת בשרשרת החל מהחוליה שהיא מקבלת. בסעיף ב׳ מזמנים אותה בתוך לולאה, בדרך כלל פעם אחת לכל חוליה.
  • יש שאלות שבהן הערך שבחוליה הוא עצם. לדוגמה: משחק שיש לו שם ומחיר, ספרה ומספר המופעים שלה, טווח של מספרים או תור. אל תכונה של העצם ניגשים כך: p.GetValue().GetPrice().
  • יש שאלות שבהן השרשרת היא תכונה של מחלקה. בשאלות כאלה הפעולה היא פעולה פנימית של המחלקה. היא אינה מחזירה את ראש השרשרת אלא מעדכנת את התכונה כשהחוליה הראשונה מתחלפת.
  • יש שאלות שכוללות גם סעיף סיבוכיות. בסעיף כזה קובעים את סיבוכיות זמן הריצה ומנמקים. יש שאלות שדורשות מראש פתרון בסיבוכיות מסוימת, לדוגמה O(n).

מקרי קצה שהשאלות בודקות

  • מחיקה של כמה חוליות רצופות מתחילת השרשרת. יש שאלות שבדוגמה שלהן שתי החוליות הראשונות נמחקות. פתרון שמוחק רק חוליה ראשונה אחת או שמתקדם אחרי כל מחיקה נכשל בדוגמה כזאת.
  • מספר שגדול מאורך השרשרת. כשהפעולה צריכה לעבור על len חוליות, len יכול להיות גדול ממספר החוליות שבשרשרת. לכן תנאי הלולאה בודק גם שהמונה קטן מ־len וגם ש־p != null.
  • שרשרת אחת קצרה מהאחרת. כשמשווים שתי שרשראות, כל אחת מהן יכולה להסתיים לפני האחרת. לכן בודקים ששתי ההפניות אינן null.
  • התחלה מכל חוליה. כשמחפשים שרשרת אחת בתוך שרשרת אחרת, מתקדמים חוליה אחת בלבד אחרי כל ניסיון שנכשל. לדוגמה: 1→2 נמצאת בתוך 1→1→2 רק החל מהחוליה השנייה.
  • השוואה בין שני חלקים של השרשרת. כשכל ערך בחצי הראשון צריך להיות קטן מכל ערך בחצי השני, משווים את המקסימום של החצי הראשון למינימום של החצי השני ולא חוליה מול חוליה.

שאלות המעקב: פעולה רקורסיבית שמחזירה חוליה

לדוגמה: הפעולה What(lst, x) מוחקת מהשרשרת את כל החוליות שערכן x ומחזירה את ראש השרשרת. אם ערך החוליה הראשונה הוא 1, בזימון What(lst, 1) גם החוליה הראשונה נמחקת. לכן מציגים את השרשרת שמתחילה בחוליה שהפעולה מחזירה ולא את השרשרת שמתחילה ב־lst.

בהמשך אותה שאלה מופיעה פעולה נוספת, Guess, שעוברת על החוליות. לכל חוליה היא מזמנת את What על החוליות שאחריה עם הערך של אותה חוליה. כך נשאר מכל ערך רק המופע הראשון. הסיבוכיות של Guess היא O(n²).

דוגמה נוספת: הפעולה Sod1(lst, ch) מקבלת שרשרת של תווים ותו ch ומחזירה הפניה לחוליה הראשונה שערכה ch. כשאין חוליה כזאת היא מחזירה null. במעקב כותבים שהפעולה מחזירה חוליה ולא תו. כשצריך לבדוק אם תו אחד מופיע בשרשרת מיד אחרי תו אחר, מזמנים את Sod1 פעם לכל תו, שומרים את שתי ההפניות במשתנים a ו־b ובודקים: a != null && a.GetNext() == b.

הסבר על מעקב אחרי רקורסיה נמצא בדף הרקורסיה.

טעויות נפוצות

כל שורה כאן מתארת טעות שתלמידים עושים ולא הנחיה.

בכתיבה

  • פונים ל־p.GetNext().GetValue() בלי לבדוק ש־p.GetNext() אינה null.
  • כותבים p != null בלולאה שצריכה לעצור על החוליה האחרונה.
  • מוחקים חוליה וגם מתקדמים. כשיש שתי חוליות רצופות למחיקה, השנייה נשארת בשרשרת.
  • שוכחים שהחוליה הראשונה יכולה להתחלף או משנים את lst בתוך הפעולה ולא מחזירים אותה. המשתנה של מי שזימן את הפעולה ממשיך להפנות לחוליה הראשונה הישנה.
  • מזמנים פעולה שמחזירה הפניה לחוליה הראשונה החדשה בלי לשמור את הערך המוחזר: RemoveAll(lst, x); במקום lst = RemoveAll(lst, x);
  • בהכנסה אחרי p מבצעים את p.SetNext(q) לפני q.SetNext(p.GetNext()) והמשך השרשרת אובד.
  • מתקדמים בלולאה עם lst עצמה בפעולה שצריכה להחזיר את ראש השרשרת.
  • משנים את השרשרת בשאלה שנכתב בה שחובה לשמור עליה.
  • מכניסים חוליות בתחילת השרשרת כשהתוצאה צריכה להישאר באותו סדר.
  • מאתחלים מקסימום ב־0 כשבשרשרת יכולים להיות מספרים שליליים.

במעקב ובסיבוכיות

  • משנים חץ בסרטוט בגלל ההוראה p = p.GetNext(). ההוראה הזאת מזיזה רק את התווית p.
  • מציגים את השרשרת שמתחילה ב־lst המקורית במקום את השרשרת שהפעולה מחזירה.
  • מניחים שפעולה ששינתה הפניות יצרה עותק של השרשרת. כל המשתנים שמפנים לאותן חוליות רואים את השינוי.
  • קובעים O(n²) לשתי סריקות שבאות זו אחרי זו.
  • קובעים O(n) לפעולה שיש בה לולאה אחת ולא שמים לב שבתוך הלולאה מזומנת פעולה שסורקת את השרשרת.
  • כותבים סיבוכיות בלי להגדיר את n ובלי לנמק.
  • כותבים שהפעולה מחזירה ערך כשהיא מחזירה הפניה לחוליה.
