מדעי המחשב, שאלה לדוגמה- 1 -רקורסיה

שאלה 1 (25 נקודות)

שליח נמצא בתחילת רחוב ובו n בניינים, הממוספרים 1 עד n. השליח עומד לפני בניין 1, בנקודת ההתחלה (מסומנת 0). בכל נסיעה הוא יכול להתקדם בניין אחד או שני בניינים קדימה. המשלוח צריך להגיע בדיוק לבניין n.

שימו לב שלשליח יש כמה דרכים שונות להגיע לבניין. למשל, אל בניין 3 יש לו 3 דרכי הגעה שונות:

דרך 10 → 1 → 2 → 3
דרך 20 → 1 → 3
דרך 30 → 2 → 3

שימו לב: דרך 2 ודרך 3 שונות זו מזו, מכיוון שהשליח עוצר בבניינים שונים.

  1. א. כתבו פעולה רקורסיבית public static int Ways(int n), המקבלת את מספר הבניין n ומחזירה את מספר דרכי ההגעה השונות שבהן השליח יכול להגיע מנקודת ההתחלה אל בניין n.
  2. ב. לשליח נוספה אפשרות: בנסיעה אחת הוא יכול להתקדם בניין אחד, שני בניינים או חמישה בניינים. כתבו פעולה רקורסיבית public static int Ways5(int n), המחזירה את מספר דרכי ההגעה השונות אל בניין n במצב החדש.
  3. ג. כתבו מה תחזיר הפעולה Ways5(4). עליכם להראות מעקב. אם ערכה של קריאה כבר חושב במעקב, מותר להשתמש בו שוב, בתנאי שתציינו זאת.
  4. ד.
    1. (1) מהו סוג הרקורסיה בפעולה Ways? נמקו.
    2. (2) מהי סיבוכיות זמן הריצה של Ways(n)? ומהי של Ways5(n)? נמקו.

שליח ברחוב סעיף א׳

שליח של וולט נמצא בתחילת רחוב ובו n בניינים, הממוספרים 1 עד n.

השליח עומד לפני בניין 1, בנקודת ההתחלה (מסומנת 0).

בכל נסיעה הוא יכול להתקדם בניין אחד או שני בניינים קדימה.

המשלוח צריך להגיע בדיוק לבניין n.

לשליח יש כמה דרכים להגיע לבניין למשל, אל בניין 3 יש לו 3 דרכי הגעה שונות

סעיף א׳

כתבו פעולה רקורסיבית:
public static int Ways(int n)
הפעולה מקבלת את מספר הבניין n ומחזירה את מספר דרכי ההגעה השונות שבהן השליח יכול להגיע מנקודת ההתחלה אל בניין n.

איך ניגשים לבעיה? חושבים על הנסיעה האחרונה

אם השליח הגיע לבניין n בנסיעה של בניין אחד, לפני כן הוא היה בבניין n − 1.

ואם הגיע בנסיעה של שני בניינים, לפני כן הוא היה בבניין n − 2.

אם נחשב את מספר הדרכים אל הבניין הקודם ואל הבניין שלפניו ונחבר אותן, נגיע לפתרון:

Ways(n) = Ways(n−1) + Ways(n−2)

שלושה דברים שצריך לחשוב עליהם

1

תנאי עצירה

מתי התשובה ידועה בלי רקורסיה? אל בניין 1 יש דרך אחת ואל בניין 2 יש שתיים (1+1 או 2). בלי שני התנאים האלה הרקורסיה תגיע ל־Ways(0) ול־Ways(−1) ולא תיעצר.

✓ נוסף לקוד
2

קריאה רקורסיבית

מה הפרמטרים של הקריאה הרקורסיבית? n − 1 ו־n − 2. זו אותה בעיה, רק קטנה יותר: הדרכים אל הבניין הקודם ואל הבניין שלפניו.

✓ נוסף לקוד
3

שילוב התוצאות

מה עושים עם מה שחזר? כאן מחברים, כי כל דרך אל n מסתיימת באחת משתי הנסיעות ונספרת פעם אחת בלבד.

✓ נוסף לקוד
public static int Ways(int n)
{
    // 1. תנאי עצירה    if (n == 1)
        return 1;        // דרך אחת: נסיעה של 1
    if (n == 2)
        return 2;        // שתי דרכים: 1+1 או 2
    // 2. קריאה רקורסיבית    int p1 = Ways(n - 1);  // השליח הגיע מבניין n−1
    int p2 = Ways(n - 2);  // השליח הגיע מבניין n−2
    // 3. שילוב התוצאות    return p1 + p2;
}

סעיף ב׳ הרחבה

לשליח נוספה אפשרות: בנסיעה אחת הוא יכול להתקדם בניין אחד, שני בניינים או חמישה בניינים.

כתבו פעולה רקורסיבית:
public static int Ways5(int n)
הפעולה מחזירה את מספר דרכי ההגעה השונות אל בניין n במצב החדש.

מה משתנה? הקריאה השלישית ברורה. מה עם תנאי העצירה?

1

תנאי עצירה

למה n == 1 ו־n == 2 כבר לא מספיקים? כי Ways5(3) קוראת ל־Ways5(−2) ולא נעצרת. במקומם בודקים n == 0 ו־n < 0.

✓ נוסף לקוד
2

קריאה רקורסיבית

מה הפרמטרים עכשיו? n − 1, n − 2 ו־n − 5, לפי הבניין שממנו הגיע השליח בנסיעה האחרונה.

✓ נוסף לקוד
3

שילוב התוצאות

מה עושים עם מה שחזר? כמו קודם מחברים: כל דרך אל n מסתיימת באחת משלוש הנסיעות ונספרת פעם אחת.

✓ נוסף לקוד
public static int Ways5(int n)
{
    // 1. תנאי עצירה    if (n == 0)
        return 1;        // הגענו ליעד: דרך אחת
    if (n < 0)
        return 0;        // עברנו את היעד: אין דרך
    // 2. קריאה רקורסיבית    int p1 = Ways5(n - 1);
    int p2 = Ways5(n - 2);
    int p3 = Ways5(n - 5);
    // 3. שילוב התוצאות    return p1 + p2 + p3;
}

סעיף ג׳

כתבו מה תחזיר הפעולה Ways5(4).
עליכם להראות מעקב.
אם ערכה של קריאה כבר חושב במעקב, מותר להשתמש בו שוב, בתנאי שתציינו זאת.

עץ הקריאות של Ways5(4)

public static int Ways5(int n)
{
    if (n == 0)
        return 1;
    if (n < 0)
        return 0;
    int p1 = Ways5(n - 1);
    int p2 = Ways5(n - 2);
    int p3 = Ways5(n - 5);
    return p1 + p2 + p3;
}
התחלהכל לחיצה מקדמת מהלך אחד.

סעיף ד׳ (1)

מהו סוג הרקורסיה בפעולה Ways? נמקו.

הלוך־חזור.
אחרי שהקריאה הרקורסיבית חוזרת עוד יש מה לעשות: צריך לחבר את הערכים שחזרו (p1 + p2). לכן זו אינה רקורסיית זנב, שבה הקריאה הרקורסיבית היא הפעולה האחרונה והערך שלה מוחזר כמו שהוא. זו גם אינה רקורסיה הדדית, כי יש כאן פעולה אחת שקוראת לעצמה ולא שתי פעולות שקוראות זו לזו.

סעיף ד׳ (2)

מהי סיבוכיות זמן הריצה של Ways(n)? ומהי של Ways5(n)? נמקו.

Ways(n): O(2n) · Ways5(n): O(3n)
כאן הסיבוכיות היא מספר הקריאות. ב־Ways כל קריאה (שלא עצרה בתנאי העצירה) פותחת שתי קריאות חדשות וכך שוב ושוב לאורך n רמות: 2 · 2 · … · 2 = 2n. ב־Ways5 כל קריאה פותחת שלוש ולכן 3n.

למה לא n2? n2 מתאים למשל לפעולה רקורסיבית על מערך שבה יש n קריאות וכל קריאה עוברת על כל המערך. כאן כל קריאה עושה מספר קבוע של פעולות. מה שגדל הוא רק מספר הקריאות.

למה לא n? O(n) מתאים לרקורסיה שבה כל קריאה פותחת קריאה אחת: שרשרת של n קריאות. כאן כל קריאה פותחת שתיים (או שלוש) ולכן מספר הקריאות מוכפל בכל רמה: 1, 2, 4, 8, …

העץ המלא של Ways5(4) בלי שום קיצור, קריאות בשביל התשובה 5

בונוס סעיף ד׳

בעץ הקריאות הקריאה Ways5(2) מופיעה פעמיים. הסבירו מדוע זה קורה ומה זה אומר על גודל העץ כאשר n גדל.

גם Ways5(4) וגם Ways5(3) קוראות ל־Ways5(2). כל אחת מהן מחשבת אותה מחדש בלי ״לזכור״ שכבר חושבה. ככל ש־n גדל, אותם ערכים קטנים חוזרים ומופיעים בחלקים רבים של העץ. זה מקור הגידול המעריכי. במעקב הרשינו לעצמנו לכתוב ״חושב כבר״ ולקצר, אבל המחשב לא מקצר. אם הפעולה הייתה שומרת כל תוצאה שחישבה, היא הייתה צריכה לחשב רק n ערכים שונים.
