מדעי המחשב, שאלה לדוגמה- 1 -רקורסיה

שאלה 1 (25 נקודות)

שליח נמצא בתחילת רחוב ובו n בניינים, הממוספרים 1 עד n. השליח עומד לפני בניין 1, בנקודת ההתחלה (מסומנת 0). בכל נסיעה הוא יכול להתקדם בניין אחד או שני בניינים קדימה. המשלוח צריך להגיע בדיוק לבניין n.

למשל, אל בניין 3 יש לשליח 3 דרכים שונות להגיע:

דרך 10 → 1 → 2 → 3
דרך 20 → 1 → 3
דרך 30 → 2 → 3

שימו לב: דרך 2 ודרך 3 שונות זו מזו, מכיוון שהשליח עוצר בבניינים שונים.

  1. א. כתבו פעולה רקורסיבית public static int Ways(int n), המקבלת את מספר הבניין n ומחזירה את מספר הדרכים השונות שבהן השליח יכול להגיע מנקודת ההתחלה אל בניין n.
  2. ב. כתבו מה תחזיר הפעולה Ways(4). עליכם להראות מעקב.
  3. ג.
    1. (1) מהו סוג הרקורסיה בפעולה Ways? נמקו.

שליח ברחוב סעיף א׳

שליח של וולט נמצא בתחילת רחוב ובו n בניינים, הממוספרים 1 עד n.

השליח עומד לפני בניין 1, בנקודת ההתחלה (מסומנת 0).

בכל נסיעה הוא יכול להתקדם בניין אחד או שני בניינים קדימה.

המשלוח צריך להגיע בדיוק לבניין n.

אל בניין 3 יש 3 דרכים

סעיף א׳

כתבו פעולה רקורסיבית:
public static int Ways(int n)
הפעולה מקבלת את מספר הבניין n ומחזירה את מספר הדרכים השונות שבהן השליח יכול להגיע מנקודת ההתחלה אל בניין n.

איך ניגשים לבעיה? חושבים על הנסיעות האחרונות

השליח הגיע לבניין n בנסיעה של בניין אחד, ואז לפני כן היה בבניין n − 1.

או בנסיעה של שני בניינים, ואז היה בבניין n − 2.

אם נחשב את מספר הדרכים להגיע לבניין הקודם ולבניין שלפניו, ונסכום אותן, נגיע לפתרון:

Ways(n) = Ways(n−1) + Ways(n−2)

שלושה דברים שצריך לחשוב עליהם

1

תנאי עצירה

מתי התשובה ידועה בלי רקורסיה? אל בניין 1 יש דרך אחת, אל בניין 2 יש שתיים (1+1 או 2). בלי שני תנאים, הקריאה תגיע ל־Ways(0) ול־Ways(−1) ולא תעצור.

✓ נוסף לקוד
2

קריאה רקורסיבית

מה הפרמטרים של הקריאה הרקורסיבית? n − 1 ו־n − 2: בעיה קטנה יותר מאותו סוג – הדרכים אל הבניין הקודם ואל הבניין שלפניו.

✓ נוסף לקוד
3

שילוב התוצאות

מה עושים עם מה שחזר? כאן מחברים, כי כל דרך אל n שייכת בדיוק לאחת משתי הקבוצות.

✓ נוסף לקוד
public static int Ways(int n)
{
    // 1. תנאי עצירה    if (n == 1)
        return 1;        // דרך אחת: נסיעה של 1
    if (n == 2)
        return 2;        // שתי דרכים: 1+1 או 2

    // 2. קריאה רקורסיבית    int p1 = Ways(n - 1);  // הגיע מבניין n−1
    int p2 = Ways(n - 2);  // הגיע מבניין n−2
    // 3. שילוב התוצאות    return p1 + p2;
}

עץ הקריאות של Ways(4)

public static int Ways(int n)
{
    if (n == 1)
        return 1;
    if (n == 2)
        return 2;
    int p1 = Ways(n - 1);
    int p2 = Ways(n - 2);
    return p1 + p2;
}

סעיף ג׳ (1)

מהו סוג הרקורסיה בפעולה Ways? נמקו.

הלוך־חזור.
אחרי שהקריאה הרקורסיבית חוזרת נותרה עבודה: צריך לחבר את שני הערכים שחזרו (p1 + p2). לכן זו אינה רקורסיית זנב, שבה הקריאה הרקורסיבית היא הפעולה האחרונה והערך שלה מוחזר כמו שהוא. זו גם אינה רקורסיה הדדית, כי יש כאן פעולה אחת שקוראת לעצמה ולא שתי פעולות שקוראות זו לזו.

סעיף ג׳ (2)

מהי סיבוכיות זמן הריצה של Ways(n)? נמקו.

O(2n)
סיבוכיות של רקורסיה היא מספר הקריאות. כל קריאה (שאינה תנאי עצירה) פותחת שתי קריאות חדשות, וזה חוזר על עצמו עד העומק n. הכפלה בתוך הכפלה, n פעמים: 2 · 2 · … · 2 = 2n.

למה לא n2? n2 מתאים למשל לפעולה רקורסיבית על מערך שבה יש n קריאות, וכל קריאה עוברת על כל המערך: n קריאות כפול n פעולות בכל אחת. כאן כל קריאה מבצעת מספר קבוע של פעולות; מה שגדל הוא מספר הקריאות עצמו.

למה לא n? O(n) מתאים לרקורסיה שבה כל קריאה פותחת קריאה אחת, למשל מעבר על מערך מאינדקס לאינדקס: שרשרת של n קריאות. כאן כל קריאה פותחת שתיים, ולכן מספר הקריאות מוכפל בכל רמה: 1, 2, 4, 8, …

בונוס סעיף ג׳

בעץ הקריאות הפעולה Ways(2) חושבה יותר מפעם אחת. הסבירו מדוע זה קורה, ומה זה אומר על גודל העץ כאשר n גדל.

Ways(2) נדרשת גם על ידי Ways(4) וגם על ידי Ways(3), וכל קריאה מחשבת אותה מחדש בלי ״לזכור״ שכבר חושבה. ככל ש־n גדל, אותם ערכים קטנים חוזרים ומופיעים בחלקים רבים של העץ, וזה מקור הגידול המעריכי: רוב העבודה בעץ היא חזרה על חישובים שכבר נעשו. אם היינו שומרים כל תוצאה פעם אחת, היו רק n ערכים שונים לחשב.
