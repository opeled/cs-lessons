א. לפניכם הפעולה Sod, המקבלת מערך של מספרים שלמים, מקום במערך i ומספר שלם x:

public static int Sod(int[] arr, int i, int x)
{
    if (i == arr.Length)
        return 0;
    if (arr[i] == x)
        return 1 + Sod(arr, i + 1, x);
    return Sod(arr, i + 1, x);
}

ב. לפניכם הפעולה What, המקבלת מערך לא ריק של מספרים שלמים ומקום במערך i:

public static int What(int[] arr, int i)
{
    if (i == arr.Length - 1)
        return arr[i];
    int best = What(arr, i + 1);
    if (Sod(arr, 0, arr[i]) > Sod(arr, 0, best))
        return arr[i];
    return best;
}

סעיף א׳ (2)

  

    
מה עושה הפעולה Sod? הסבירו.

    

      Sod מחזירה את מספר המופעים של x מהתא i ועד סוף המערך. בקריאה Sod(arr, 0, x) היא סופרת את כל המופעים של x במערך.
    

    

      כשעוברים את התא האחרון אין מה לספור ומחזירים 0. בכל תא אחר, אם הערך שווה ל־x מוסיפים 1 לספירה של שאר המערך ואם לא, מחזירים אותה כפי שהיא.

      בדוגמה 4 נמצא בתאים 0, 2 ו־3 ולכן Sod(arr, 0, 4) = 3. הסיבוכיות היא O(n), כי יש קריאה אחת לכל תא.

סעיף ב׳ (2)

  

    
מה עושה הפעולה What? הסבירו.

    
What מחזירה את הערך השכיח ביותר במערך, הערך שמופיע הכי הרבה פעמים.

    

      What עוברת על התאים מהסוף להתחלה. בכל שלב best הוא הערך השכיח ביותר מבין התאים שכבר נבדקו. הערך שבתא i מחליף את best רק אם הוא מופיע במערך יותר פעמים ממנו.

      בדוגמה 4 מופיע 3 פעמים, 7 ו־9 פעם אחת כל אחד ולכן What(arr, 0) = 4.
      
⚠ Sod תמיד מקבלת i = 0, כלומר סופרת בכל המערך ולא רק מהתא הנוכחי והלאה.

    

  







  
סעיף ב׳ (3) סיבוכיות

  

    
מהי סיבוכיות זמן הריצה של What? נמקו.

    
O(n²). יש n קריאות ל־What ובכל אחת (חוץ מהאחרונה) שתי קריאות ל־Sod, שעוברת על כל המערך.

    

      

      
באופן כללי (n−1) · 2 · (n+1) ≈ 2n² ולכן O(n²). המבנה הזה חוזר בבגרות: פעולה רקורסיבית ב־O(n) שנקראת מתוך פעולה רקורסיבית אחרת ב־O(n).

מעקב: What(arr, 0) על {7, 4, 9, 7, 4} איזה ערך נשמר ב־best ראשון ומתי התנאי 2 > 2 לא מתקיים

  

  

    

      

      

    

    

  

  
התחלהכל לחיצה מקדמת מהלך אחד.







  
מה קובעת הפעולה בתיקו?

  

    
בגלל > ולא >=, ערך מחליף את best רק אם הוא שכיח יותר ממש. בתיקו best נשאר.

    
הפעולה מכריעה מהסוף להתחלה. לכן הערך שנשמר ב־best ראשון הוא זה שהמופע האחרון שלו קרוב יותר לסוף המערך והוא נשאר שם: בכל 7 שמגיע אחר כך התנאי 2 > 2 לא מתקיים.

    
כלל התיקו: בתיקו הפעולה מחזירה את הערך שהמופע האחרון שלו מאוחר יותר במערך. הכלל לא כתוב בקוד במפורש אלא נובע מהסדר שבו הרקורסיה מכריעה.

  







  
אתגר בנו מערך שבו 7 מנצח בתיקו

  

    
כתבו מערך שבו 4 ו־7 מופיעים אותו מספר פעמים ו־What(arr, 0) מחזירה 7.

    
מספיק להחליף את שני התאים האחרונים: {7, 4, 9, 4, 7}.

    

    
עכשיו המופע האחרון של 7 (תא 4) מאוחר מהמופע האחרון של 4 (תא 3) ולכן 7 נשמר ב־best ראשון ונשאר. ואם 7 מופיע פעם אחת יותר, הוא מנצח בכל סידור, כי זה כבר לא תיקו.
