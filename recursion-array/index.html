א. לפניכם הפעולה Sod, המקבלת מערך של מספרים שלמים, מקום במערך i ומספר שלם x:

public static int Sod(int[] arr, int i, int x)
{
    if (i == arr.Length)
        return 0;
    if (arr[i] == x)
        return 1 + Sod(arr, i + 1, x);
    return Sod(arr, i + 1, x);
}

ב. לפניכם הפעולה What, המקבלת מערך לא ריק של מספרים שלמים ומקום במערך i:

public static int What(int[] arr, int i)
{
    if (i == arr.Length - 1)
        return arr[i];
    int best = What(arr, i + 1);
    if (Sod(arr, 0, arr[i]) > Sod(arr, 0, best))
        return arr[i];
    return best;
}

      (2) מה עושה Sod: הפעולה מחזירה את מספר המופעים של x מהתא i ועד סוף המערך. בקריאה Sod(arr, 0, x) היא סופרת את כל המופעים של x במערך.

      הסבר: כשעוברים את התא האחרון אין מה לספור ומחזירים 0. בכל תא אחר, אם הערך שווה ל־x מוסיפים 1 לספירה של שאר המערך ואם לא, מחזירים אותה כפי שהיא.

      בדוגמה הערך 4 נמצא בתאים 0, 2 ו־3 ולכן Sod(arr, 0, 4) = 3.
    

    

      סיבוכיות: O(n). יש קריאה אחת לכל תא (ועוד אחת ל־i == arr.Length) ובכל קריאה מספר קבוע של פעולות. Sod תמיד עוברת עד סוף המערך, גם אם x לא מופיע בו כלל.

  1. מה עושה הפעולה What? הסבירו.
    2. 
      
  2. מהי סיבוכיות זמן הריצה של What? נמקו.
    3. 
    

    

      (2) מה עושה What: הפעולה מחזירה את הערך השכיח ביותר במערך (הערך שמופיע הכי הרבה פעמים).

      הסבר: What עוברת על התאים מהסוף להתחלה. בכל שלב best הוא הערך השכיח ביותר מבין התאים שכבר נבדקו (מתא i+1 ועד הסוף). הערך שבתא i מחליף את best רק אם הוא מופיע במערך יותר פעמים ממנו. בדוגמה 4 מופיע 3 פעמים, 7 ו־9 פעם אחת כל אחד ולכן What(arr, 0) = 4.
      
⚠ Sod תמיד מקבלת i = 0, כלומר היא סופרת בכל המערך ולא רק מהתא הנוכחי והלאה. לכן השכיחות של best נמדדת בכל המערך, גם כשנבדקו עד כה רק חלק מהתאים.

    

    

      (3) סיבוכיות: O(n²).

      What מבצעת n קריאות (אחת לכל תא). בכל קריאה, חוץ מהאחרונה, היא קוראת פעמיים ל־Sod, שעוברת על כל המערך: n+1 קריאות בכל פעם (ראו סעיף א׳). בדוגמה:
      

      
באופן כללי (n−1) · 2 · (n+1) ≈ 2n² ולכן O(n²). המבנה הזה חוזר בבגרות: פעולה רקורסיבית ב־O(n) שנקראת מתוך פעולה רקורסיבית אחרת ב־O(n).

    

    

  







  

    סעיף ב׳ (4)
    
מה קורה בתיקו?

    
נתון המערך {7, 4, 9, 7, 4}. מה תחזיר What(arr, 0)? מה קובעת הפעולה כאשר שני ערכים מופיעים אותו מספר פעמים?

    

    

    
    
      
  1. מה תחזיר What(arr, 0) ולמה?
    2. 
    

    

      התשובה: 4. גם 4 וגם 7 מופיעים פעמיים.

      בגלל > (ולא >=), ערך מחליף את best רק אם הוא שכיח יותר ממש. בתיקו best נשאר. מכיוון שהפעולה מכריעה מהסוף להתחלה, הערך שנשמר ב־best ראשון הוא זה שהמופע האחרון שלו קרוב יותר לסוף המערך והוא נשאר שם עד הסוף.

      כאן המופע האחרון של 4 הוא בתא 4 והמופע האחרון של 7 הוא בתא 3. ברגע ש־4 נשמר ב־best, 7 כבר לא מחליף אותו (התנאי 2 > 2 אינו מתקיים).
      
⚠ כלל התיקו: בתיקו הפעולה מחזירה את הערך שהמופע האחרון שלו מאוחר יותר במערך. הכלל לא כתוב בקוד במפורש אלא נובע מהסדר שבו הרקורסיה מכריעה.

        פתרון אפשרי
        

        

          
מספיק להחליף את שני התאים האחרונים של המערך מהשאלה: 7, 4, 9, 4, 7. עכשיו המופע האחרון של 7 (תא 4) מאוחר מהמופע האחרון של 4 (תא 3) ולכן 7 נשמר ב־best ראשון ונשאר.

          
נסו גם מערך שבו 7 מופיע פעם אחת יותר. אז הוא מנצח בכל סידור, כי זה כבר לא תיקו.
