# cs-lessons

דפי שיעור אינטראקטיביים במדעי המחשב (כיתה י"ב, לקראת הבגרות). כל שיעור הוא תיקייה עם דף מלא (`index.html`) ומצגת (`slides.html`).

| שיעור | דף | מצגת |
|---|---|---|
| רקורסיה: שליח ברחוב | [recursion/](https://opeled.github.io/cs-lessons/recursion/) | [recursion/slides.html](https://opeled.github.io/cs-lessons/recursion/slides.html) |
| רקורסיה על שרשרת חוליות: הרצף העולה | [recursion-list/](https://opeled.github.io/cs-lessons/recursion-list/) | [recursion-list/slides.html](https://opeled.github.io/cs-lessons/recursion-list/slides.html) |
| רקורסיה על מערך: הערך השכיח | [recursion-array/](https://opeled.github.io/cs-lessons/recursion-array/) | [recursion-array/slides.html](https://opeled.github.io/cs-lessons/recursion-array/slides.html) |

התיקייה `lib/` מכילה את מנוע המעקב המשותף (`trace.js`) ואת גיליונות הסגנון של מצב הדף ומצב המצגת לשיעורי ״מה עושה הפעולה״.
